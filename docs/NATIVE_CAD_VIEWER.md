# 原生二维 CAD 交互视图

工作台打开 DXF 时，模型空间现在通过 ezdxf 绘图管线生成 SVG 路径。
圆弧保留起止角，多段线保留凸度，椭圆保留方向，填充保留孔洞；
块、属性与尺寸标注显示其实际图形。预览读取原文件，不重写图纸。

## 交互

- 点击图形切换选择；轮廓较细时也有沿实际路径的点击范围。
- 滚轮围绕鼠标缩放；中键、空白处或按住空格拖动可平移。
- Shift 拖动选择完全落在窗口内的对象；Ctrl/Command 可追加选择。
- 「适合窗口」「放大选中」调整视图；双击对象放大。
- 图层开关只影响预览。原本关闭/冻结的图层可临时查看，不修改 DXF。
- 移动、旋转、删除、文字更新、选择集以及撤销/重做仍通过统一 CAD 事务执行。
- 保存后按世界坐标恢复视角、选择和显示图层。即使编辑改变整体几何范围，
  画面也不会无故跳回全图；需要查看移出窗口的对象时点击「适合窗口」。

嵌套块和尺寸标注会生成多条路径；这些路径归属同一个顶层可编辑实体。
点击块内轮廓、属性或尺寸箭头，选中的是对应 INSERT / DIMENSION，
不会把匿名块中的临时图元当成独立模型实体修改。

## 图层、图元与完整性

显示路径记录顶层实体 ID、handle、实际图层及父块图层。
隐藏父块图层会隐藏整个块；隐藏块内部图层只隐藏属于该图层的内容。
初始缩放范围不计入原本不可见的远处图元。

API 的 `asset.cad_view` 包含源 DXF 哈希、实体/绘图路径数量、世界坐标映射和
渲染提示。暂不支持的对象、缺字或空图会明确提示。路径数量与实体数量不同；
两者都不能单独证明图形完整或工程语义正确。

每份预览最多 100,000 条绘图记录和 30 MB SVG。超过限制会报错，不截断后假装成功。
界面限制并不代表已对同等规模的客户图纸完成性能验收。

## 验证

```bash
python -m pytest tests/test_cad_viewer.py tests/test_cad_editing.py -q
node tests/browser/cad_viewer.cjs
node tests/browser/cad_editor.cjs
```

测试使用独立 ezdxf fixture：圆弧、半圆凸度多段线、旋转椭圆、嵌套块/属性、
带孔填充和原生尺寸标注。浏览器实际计算 SVG 几何范围并与解析值比较，
检查孔洞的点击行为、图层祖先关系、框选、缩放、平移和事务写入。
另有 1,200 个实体的完整性测试；这不是工业大图性能基准。

当前渲染范围是二维模型空间；纸空间图纸仍使用单独的出图预览。
栅格 IMAGE、部分代理图元和复杂字体不能完整显示。曲线通过原生绘图管线
转换为矢量路径，并非通用精确几何约束求解器。
框选要求对象全部落在窗口内，尚无交叉窗口、对象捕捉、夹点编辑或完整制图命令栏。
「逐个高亮」展示当前对象，不是历史操作重放。
